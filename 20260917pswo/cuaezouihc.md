# 【科普】怀孕必知的7个惊人发现

> 更新时间：2026-09-17 (UTC+8)

**发现1：怀孕时滴酒不沾更安全**　　针对孕期饮酒这个问题，以往专家的意见是，只要不是酗酒，偶尔少量饮用没关系。位于美国底特律的密歇根儿童医院和韦恩州立大学的专家在最近的一项研究中得出一个新的结论，即使是非常微量的酒精都会对胎儿产生危害。在这项研究中，专家们调查了506名准妈妈，并在她们的孩子长到6-7岁的时候对孩子的行为举止进行了测试。结果发现，在怀孕时平均每周喝一杯鸡尾酒的准妈妈所生的孩子存在行为问题的比例是那些从不喝酒的准妈妈的3倍。　　这些行为问题包括攻击性强、注意力不集中、学习障碍等，而这些问题普遍是与酒精相关的神经混乱症状。　　研究专家表示：迄今为止，我们还没有足够的证据明确指出，准妈妈在何时可以喝酒或者说喝多少合适，所以最安全的选择就是不喝酒。与酒精相关的神经混乱症状与胎儿酒精综合征是两种不同的症状，后者一般是指大量饮酒后引起的比较严重的身体缺陷如低智商和协调能力差等，而前者指的则是那些不容易判别的认知和行为举止方面的问题。　　那么，万一你在不知道怀孕的情况下喝了酒怎么办呢？专家表示：那也不必恐慌，将情况告诉医生，他会密切关注胎儿的发展，如果需要还可以采取必要的措施。**发现2：剖腹产后18个月内再次阴道分娩具有危险性**　　美国妇科医院最近进行的一项调查称，如果在剖宫产后的18个月内尝试阴道分娩，因为剖宫产造成的子宫内壁上的伤疤还没有完全愈合，会有导致子宫破裂的危险性。专家表示：最安全的办法就是仔细计算好两次怀孕的间隔时间。(密歇根社区卫生部进行的另一项调查发现两次怀孕间隔18-23周，就可以把生育低体重儿的可能性降到最低)。不过调查还显示，只要怀孕间隔时间超过19个月，无论是20个月还是24个月，发生子宫破裂的几率几乎没什么差别。**发现3：抑郁症在孕期和产后发生的机率相同**　　英格兰妇产专家最近通过对9000位准妈妈的调查，发现差不多有近1/10的人受到孕期抑郁症的困扰。       专家表示：由于孕期的很多反应和抑郁症的症状很相似，所以不太好辨别是否为孕期抑郁症。在孕期，嗜睡(一种睡眠模式的改变)，胃口大增或者没有胃口等普通抑郁症的表现会经常发生，情绪变化可能更为明显，专家提醒，如果一位准妈妈情绪低落而且保持持续低落的状态，就应该引起注意了。　　虽未经证实，但孕期抑郁症一般会增加产后抑郁症发生的危险性。所以，如果准妈妈怀疑自己的情绪总是低落却又找不到原因，最好去咨询医生。某些抗抑郁症的药物是可以在怀孕期间服用的。专家还建议，家人或朋友可以帮助准妈妈改善睡眠、一起制作丰盛可口的食物或者一起去散步，这些都会对症状不是十分严重的准妈妈的抑郁情绪有缓解作用。**发现4：孕妇每天30分钟锻炼，安全且可保身体健康**　　以前，医生一般会建议健康的准妈妈每周可以锻炼3-4次。　　今年年初，位于华盛顿的美国妇产科医师学会发表了最新的关于孕妇锻炼的建议，鼓励那些没有任何高危症状的准妈妈每天至少适当锻炼30分钟，即使不能做到每天锻炼，也要尽量每周多锻炼几次。　　适当锻炼的内容包括散步、游泳、室内脚踏自行车等。圣路易大学医学院妇产科教授博士也提出了自己的观点：与之前人们普遍认定的锻炼项目相比，最近的研究证实妇女在怀孕期间完全可以进行更广泛的体育运动。博士说：在开始锻炼之前，一定要先征求医生的意见，如果医生认为可以，即使在孕前从不进行锻炼的准妈妈也可以在怀孕时开始锻炼。他认为，体育锻炼不但可以在身体上和精神上给准妈妈带来益处，同时也有助于胎儿的发育。”研究还发现锻炼还可以预防妊娠期糖尿病。但准妈妈在运动时应该避免那些容易摔倒或者容易对腹部产生危害的运动，如篮球、足球、滑雪以及骑马等。**发现5：产前体重增加过多在产后容易导致肥胖**　　马里兰州贝塞斯达国立卫生研究院对577名女性进行了跟踪调查，发现那些在怀孕期间体重增加超过标准值的女性，在生产一年之后成为胖子的可能性是那些将体重控制在标准范围内的准妈妈的4倍。如果BMI值达到28及以上即表示肥胖，会增加患心脏疾病、II型糖尿病、关节炎以及部分癌症的风险。　　纽约的康奈尔大学营养学专家建议：大多数女性都可以尝试减掉多余的脂肪，但如果增长过多(除正常的体重增长外，超过5kg以上)，就不太容易恢复正常了。一般情况下，在进行产前检查的时候，医生都会针对体重增长给准妈妈提一些建议，那些没有得到过任何建议的准妈妈更容易超重。其实，准妈妈所需的热量并没有她们想象的那么多，一般每天只比怀孕前多增加300卡的热量就够了。**发现6：吃加餐可以降低早产的风险**　　北卡罗莱纳大学及卡罗莱纳人口学中心的专家经过研究发现：包括早餐在内的三顿正餐如果营养均衡，在加上上下午各一次的两顿加餐，这样的饮食结构和规律对准妈妈是最有好处的。　　调查还发现如果准妈妈超过13个小时没有吃东西(含睡觉时间)，那么她们早产的机率会上升30%。此次调查的主要博士解释说：这种超过12小时没有进食的情况如果频繁发生，就会成为一种紧张刺激体，容易导致准妈妈发生早产。　　长期的饥饿还会引发一连串的不良反应，给身体带来某种暗示。博士建议准妈妈都应该随身携带一些健康简便的食物，如酸奶、玉米片、小块奶酪、水果或是小胡萝卜等蔬菜。另外，她还特别强调准妈妈一定要吃好早餐。**发现7：怀孕引起的高血压比例日渐升高**　　马里兰州贝塞斯达的国立卫生统计中心称，妊娠高血压综合征(一种很严重的孕期合并症)的发生越来越频繁，在过去的10年中增幅高达40%。专家认为这应该归咎于高危孕妇的增加，尤其是那些年龄达到35岁或以上的准妈妈以及那些怀有双胞胎或多胞胎的准妈妈。　　匹兹堡女性医院的负责人，妊高征的资深专家博士说：越来越多的女性推迟了生育的年龄，而高血压的风险是随着年龄的增长而增加的。同时匹兹堡大学妇产科教授的博士也表示，在怀多胞胎时，为了满足胎儿对养分的需求，胎盘不断长大(即便如此，也未必能够满足多个胎儿的需求)，从而导致准妈妈出现某些疾病。　　妊高征会引起血管痉挛，如果能够早期发现病情可以得到控制。妊高征的前期表现是水肿和尿液中出现蛋白。如果认真进行产前检查，就能够及时发现。不过，一旦出现视力模糊(或者视线中总是出现小点或闪烁的光线等)、头痛、严重呕吐等情况，不要等到下一次产前体检，应该立刻去看医生。——内容来源于网络，如有侵权请及时联系，谢谢！
