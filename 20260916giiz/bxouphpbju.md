# 海口市妇幼保健院与北京儿童医院签约合作——让百姓家门口看北京专家

> 更新时间：2026-09-16 (UTC+8)

**海口市妇幼保健院与北京儿童医院签约合作——让百姓家门口看北京专家**

      9月1日，海口市妇幼保健院与首都医科大学附属北京儿童医院（简称“北京儿童医院”）举行技术合作签约仪式，双方将在医疗技术、人才培养、学科建设、教学培训、远程会诊、双向转诊等方面进行合作，让海南百姓在家门口就能享受到北京一流的优质诊疗服务。

（9月1日，海口市妇幼保健院与首都医科大学附属北京儿童医院举行技术合作签约仪式）

      目前，北京儿童医院首次派出的泌尿外科主任医师、医学博士韩文文教授已到海口市妇幼保健院坐诊。韩文文教授曾进修于美国费城儿童医院，擅长小儿泌尿外科、小儿外科各种畸形手术，每年主刀完成近千例小儿泌尿外科手术。

      今后，北京儿童医院还将结合海南儿童患者的需要和海口市妇幼保健院未来的发展需求，派出不同专业队伍，对小儿外科其他亚专业、小儿内科各亚专业、耳鼻喉头颈外科、新生儿、儿童重症等专业提供技术支持，为更多的患者提供诊疗救治。

      “未来合作中，我们将吸取北京儿童医院管理经验，紧密对接各优势学科，努力在学科建设、人才队伍培养、科研教学等取得新突破。”海口市妇幼保健院院长林白浪表示，将不断提升医院管理水平、诊治能力和技术能力，为推进健康海口建设，为海南自贸港建设作出新的更大贡献。

（9月1日，海口市妇幼保健院与首都医科大学附属北京儿童医院举行技术合作签约仪式）

      北京儿童医院院长倪鑫表示，要把儿科健康事业做好，关键在于把产儿联动起来，实现产儿一体化；今后将结合海口市妇幼保健院的发展需求，不断地派出不同专业人才支持，帮助医院增强造血功能，让海口市以及海南省妇女儿童真正受益。

      国家儿童医学中心、北京儿童医院是一家集医疗、科研、教学、保健于一体的三级甲等综合性儿科医院，拥有12个国家级平台，8个国家临床重点专科，5个北京市重点实验室，2个北京市级研究平台以及16个市级医疗中心。

      海口市妇幼保健院是一家三级甲等妇幼保健院，是海口市妇幼保健技术指导、业务培训中心、孕产妇保健基地、孕产妇危重症救治中心和新生儿危重症救治中心，年分娩量约占海口市分娩总量的1/4。目前，海口市妇幼保健院江东新院区正在建设，预计今年完成项目建设，将迎来新的发展机遇。

      海口市卫生健康委员会党组书记、主任潘文利表示，近年来海口市儿童医疗卫生服务体系建设取得显著成效，全面完成两纲两规指标要求。其中，海口市妇幼保健院在儿科的学科建设、医疗服务、科研教学等方面均实现新突破，进入高质量发展新阶段，医院应以此次合作为契机，整合区域儿童医疗卫生资源，提供安全、有效、方便、经济、公平的儿童医疗服务，为促进海口市儿童健康事业发展再谱新篇章。

      据了解，近年来海南大力引进国内优质医疗资源，目前累计已有北京、上海、四川等10余省份的五十余家医院和院校进驻海南，并与海南省各级医院以托管、集团、技术支援、远程医疗等多种形式建立了帮扶合作关系，有力提升了海南省大病保障能力，促进了优质医疗资源下沉，人民群众就医获得感、体验感不断增强。特别是急危重症救治能力、疑难杂症诊疗能力得到极大提升，多项新技术新项目不断填补空白，筑牢了大病不出岛最后一道防线。
